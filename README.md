## О проекте

Учебный fullstack-проект. Представляет собой интернет-магазин: каталог товаров, просмотр карточек и оформление заказа. Название «5R» отсылает к принципам разумного потребления (reduce, reuse, recycle и др.).

## Возможности

- Каталог товаров с карточками
- Корзина и оформление заказа
- Управление состоянием приложения через Redux
